# kr2-bootstrap-service

Контрольная работа №2 по дисциплине «Фронтенд и бэкенд разработка».

## Контрольная работа №2

Тема: «CSS-фреймворки: разработка интерфейса на Bootstrap или альтернативном CSS-фреймворке».

## Описание

MR CYBORG - сайт сервисного центра по ремонту ноутбуков, смартфонов и компьютеров.
Посетитель может посмотреть каталог услуг с ценами, открыть страницу услуги со сроками
и гарантией, задать вопрос в блоке частых вопросов и оставить заявку на ремонт -
через отдельную страницу с выбранной услугой.

Проект выполнен заново на Bootstrap и не является адаптацией контрольной работы №1.

## Используемый фреймворк

Bootstrap 5.3.3.

## Способ подключения

Bootstrap подключён локально, файлы фреймворка лежат в папке `vendor/bootstrap/`:

- `vendor/bootstrap/css/bootstrap.min.css`;
- `vendor/bootstrap/js/bootstrap.bundle.min.js`.

Собственный `css/custom.css` подключается после Bootstrap, чтобы его правила могли
перекрывать стандартные. CDN не используется: сайт открывается без интернета.

## Реализованные компоненты

- `navbar` с `navbar-toggler`, `collapse`;
- сетка: `container`, `row`, `col-12`, `col-md-*`, `col-lg-*`, `g-3`, `g-4`;
- `card` - карточки услуг, блок формы заявки, карточка услуги;
- `btn` - `btn-primary`, `btn-outline-primary`, `btn-outline-secondary`, `btn-lg`;
- `badge` - метки «Хит», «Сезон», «Срочно», «Онлайн»;
- `alert` - `alert-info`, `alert-warning`, `alert-success`;
- `form-control`, `form-select`, `input-group`, `form-check` - формы;
- `needs-validation` и `invalid-feedback` - встроенная валидация Bootstrap;
- `accordion` - частые вопросы в каталоге;
- `nav-tabs` и `tab-content` - вкладки на странице услуги;
- `breadcrumb` — навигационная цепочка на страницах услуг.

## Самостоятельные доработки

- Bootstrap подключён локально, без CDN.
- Каталог содержит шесть услуг ремонта и подготовку ПК для киберспорта.
- Каждая карточка ведёт на свою страницу с описанием, сроками и условиями.
- Страница услуги дополнена вкладками «Что входит», «Сроки» и «Гарантия».
- Форма заявки автоматически выбирает услугу при переходе с её страницы.
- Для киберспортивного апгрейда рассчитывается скидка по уровню FACEIT.
- Телефон оформлен через `input-group` с префиксом `+7` и проверкой формата.
- Единое меню на всех страницах и мобильная навигация.
- Блок частых вопросов на `accordion`.
- Проверка телефона, имени и профиля FACEIT.
- Заполненная заявка скачивается в файл; онлайн-отправка не подключена.
- Тёмная адаптивная тема с красными и синими акцентами.
- Версии ссылок на страницы и ресурсы для обновления кэша.

## Пять интерактивных функций

1. **Чат MR CYBORG.** Бот отвечает о ремонте, ценах, диагностике, гарантии и контактах; показывает «печатает». История сохраняется при переходах между страницами в текущей вкладке (`sessionStorage`). Ответы основаны на правилах, внешний ИИ и онлайн-оператор не подключены.
2. **Поиск по сайту.** Живой поиск по 11 услугам, описаниям и разделам; переход на соответствующую страницу. Открывается кнопкой или Ctrl/Cmd + K, закрывается Escape.
3. **Светлая и тёмная темы.** Фирменная тёмная тема по умолчанию, выбор сохраняется в `localStorage`. Переключение с круговой анимацией через View Transitions; в остальных браузерах — плавная смена цветов.
4. **Анимации.** Появление карточек при прокрутке, подсветка логотипа, мигание курсора терминала, появление окон и сообщений. Настройка «уменьшить движение» отключает анимации.
5. **Подбор ремонта по симптому.** Выбор устройства и проблемы → предварительная рекомендация, начальная цена, описание услуги и переход в заявку с уже выбранной услугой. Это ориентир, окончательное решение принимается после диагностики.

Функции доступны на всех 17 содержательных страницах; `product.html` сохраняет перенаправление. Общая логика — `js/features.js`, раннее применение темы — `js/theme.js`, оформление — `css/features.css`. Работают без сборки и внешних библиотек, кроме уже подключённого Bootstrap.

### Пасхалки в терминале

На главной странице можно вводить команды: `cmatrix` запускает дождь символов, `lava` (или `lavat`) — лавовую лампу со сливающимися каплями. `help` показывает подсказку, `exit` и `clear` возвращают исходный экран. Остановка также доступна по Esc, Ctrl+C и кнопке. Стрелки ↑/↓ перебирают историю команд. Анимации приостанавливаются вне экрана и в фоновой вкладке; при уменьшении движения отображается статичный кадр.
