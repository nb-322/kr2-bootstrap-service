# Контрольная работа №2

Тема: «CSS-фреймворки: разработка интерфейса на Bootstrap или альтернативном CSS-фреймворке».

## Описание

ФиксЛаб - учебный сайт сервиса по ремонту ноутбуков, телефонов и компьютеров.
Проект представляет собой каталог услуг с карточками, страницей услуги и формой заявки,
собранный на Bootstrap.

## Практическая работа 9

Выполнена главная страница на Bootstrap-сетке.

Реализовано:

- подключение Bootstrap 5.3.3 через CDN;
- подключение `css/custom.css` после Bootstrap;
- подключение Bootstrap JS Bundle;
- шапка страницы на `container`, `row`, `col-md-8` и `col-md-4`;
- Bootstrap-навигация `navbar` со сворачиванием на малых экранах;
- hero-блок в две колонки `col-12 col-lg-6`;
- блок преимуществ `col-12 col-md-4`;
- сетка частых услуг `col-12 col-md-6 col-lg-4`;
- подвал страницы на сетке.

## Используемые технологии
